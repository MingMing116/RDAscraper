4단계로 끝내는 기사 스크랩

  1. 자료 입력

    파일을 선택하거나 보도자료 제목·본문을 붙여넣고 분석합니다.

  2. 날짜 확인 후 검색

    배포일과 종료일을 확인하세요. 검색어 조합은 자동 생성됩니다.

  3. 원문 확인 · 기사 선택

    행을 눌러 선택하고 제목을 눌러 원문을 확인하세요. 날짜나 기관 근거가 부족한 기사는 ‘확인 필요’에 남습니다.

  4. 선택 기사 저장

    엑셀 XLSX는 행 높이가 30pt로 고정됩니다. CSV는 줄바꿈을 정리한 데이터 파일입니다. 검수 목록 PDF에는 선택한 기사의 번호·기사일·매체·제목·발췌문·원문 링크가 기사 번호순으로 정리됩니다. 기사 전체 내용은 원문 링크에서 확인하세요.

화면이 열리지 않을 때

RDAscraper.exe를 다시 실행하세요. 화면이 준비된 뒤 자동으로 열립니다. 예전 즐겨찾기 대신 EXE로 시작하세요.

이미지 · 스캔 PDF

PNG·JPG·WEBP·BMP와 글자가 없는 PDF는 한국어·영어 OCR로 읽습니다. 글자가 깨진 PDF는 ‘PDF 전체를 OCR로 읽기’를 선택해 다시 분석하세요. OCR은 최대 20쪽이며, 결과의 제목·핵심어를 확인하세요.

처음부터 다시 시작

왼쪽 상단 RDAscraper 로고를 누르면 진행 중인 작업과 자동 저장 내용을 초기화합니다. 보관할 작업은 먼저 ‘작업 저장’으로 내려받으세요.

 WORKSPACE SETTINGS

작업 보관을 직접 선택하세요

자동 저장에는 보도자료 본문, 검색어와 기사 정보가 포함됩니다. 사용자 PC와 브라우저에 암호화되지 않은 상태로 보관합니다.

자동 저장을 끄면 기존 자동 저장본과 실행 로그를 삭제합니다. 지금 화면의 작업은 유지되며, 필요한 내용은 상단의 ‘작업 저장’으로 직접 내려받을 수 있습니다.

직접 내려받은 JSON·XLSX·CSV·PDF와 원본 문서는 삭제하지 않습니다. 왼쪽 상단 로고는 화면을 초기화하는 기능입니다.
