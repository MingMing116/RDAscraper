# 글자 크기와 새 실행파일 적용

## 창 크기에 맞는 글자와 메뉴

프로그램은 **Noto Sans KR Bold**를 포함합니다. 글꼴을 따로 설치하지 않아도 화면과 PDF에 굵은 한글 글꼴을 사용합니다. 이번 화면은 이전보다 전체 크기를 조금 줄이고 창 너비에 따라 글자·메뉴·간격을 조절합니다.

상단 **글자 크기**에서 원하는 크기를 고릅니다.

| 선택 | 기본 글자 범위 | 사용 |
| --- | --- | --- |
| 보통 | 18–19px | 처음 실행할 때의 기본값 |
| 크게 | 20–21px | 화면의 글자와 입력 요소를 함께 확대 |
| 아주 크게 | 22–23px | 가장 큰 화면 글자 설정 |

각 범위 안에서 좁은 창은 작게, 넓은 창은 크게 표시합니다. 보조 설명은 최소 15px를 유지합니다. 운영체제의 최대화 여부를 직접 확인하는 대신 **브라우저에 실제로 보이는 너비**를 기준으로 바뀝니다. 최대화·복원·수동 크기 조절·화면 분할에서 모두 같은 규칙을 사용합니다. 브라우저 확대·축소도 실제 표시 공간에 영향을 줍니다.

선택한 값은 이 PC의 브라우저에 기억합니다. 프로그램을 다시 열어도 유지되며 다른 브라우저나 PC에는 각각 설정합니다. 이전 배포에서 선택한 기본·중간·최대 단계는 그대로 유지됩니다. 가로 공간이 부족하면 메뉴와 입력 영역은 다음 줄로 이동하고 기사 표는 가로로 스크롤할 수 있습니다.

PDF 크기는 화면 설정과 별도로 일정합니다. 문서 제목 26pt, 기사 제목 18pt, 본문 13pt, 날짜·매체 등 정보 12pt를 사용하며 글꼴을 PDF에 내장합니다.

Linux Chromium에서 글자 크기 3단계와 여섯 화면 너비의 18개 조합을 확인했습니다. 검사한 메뉴가 겹치거나 페이지 전체가 가로로 넘치지 않았으며, 화면이 열린 상태의 크기 변경과 새로고침 후 선택값 유지도 확인했습니다. 이 결과는 Windows의 최대화 버튼을 직접 조작한 시험은 아닙니다. [검사 범위](VALIDATION_KO.md)

## 새 EXE인데 이전 글자가 보일 때

이전 실행파일은 기존 엔진이 실행 중이면 그 화면을 다시 열었습니다. 새 파일을 눌러도 기존 엔진이 종료되지 않았다면 새 글꼴이 적용된 화면으로 바뀌지 않을 수 있습니다.

이번 실행파일은 이전 버전을 발견하면 기존 화면과 교체 안내창을 엽니다.

1. 기존 화면에서 **작업 저장**을 눌러 JSON 파일을 내려받습니다.
2. 기존 화면 상단 **종료**를 누릅니다. 창의 X만 닫으면 엔진이 남아 있을 수 있습니다.
3. 교체 안내창의 **확인**을 누릅니다. 기존 엔진 종료를 확인한 뒤 새 화면이 열립니다.
4. 필요하면 **작업 불러오기**로 저장한 JSON을 엽니다.
5. 새 화면 상단의 **글자 크기**에서 원하는 크기를 선택합니다.

아직 작업을 저장하지 않았다면 안내창을 닫지 말고 기존 화면에서 먼저 저장합니다. 교체를 진행하지 않으려면 **취소**를 누릅니다. 자동 저장을 꺼두었더라도 수동 **작업 저장**으로 JSON을 내려받을 수 있습니다.

기존 화면이 응답하지 않으면 [실행 오류 복구 안내](STARTUP_FIX_KO.md)의 절차를 따릅니다. 저장된 JSON·CSV·PDF나 프로필 폴더를 삭제하는 초기화는 필요하지 않습니다.
