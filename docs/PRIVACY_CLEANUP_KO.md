# 공개 자료의 담당자 정보 정리

> **이전 정리 이력**: 이 문서는 64.0.0 공개 자료를 준비하면서 반영한 담당자 정보 제거 조치의 기록입니다. 64.1.0에 대한 새 전수 개인정보 검사 결과나 보안 인증으로 해석하지 않습니다. 이번 배포의 새 검증 결과는 [현재 검증 기록](VALIDATION_KO.md)을 확인하세요.

## 반영 내용

- 공개를 허용한 398개 매체 분류·점수 기준표는 유지했습니다.
- 담당자 이름·부서·업무 전화번호가 들어 있던 원본 시험 문서와 문서 내부 미리보기를 배포용 소스에서 제외했습니다.
- 원본 OCR 사본과 과거 문서·기사 파생 검증 자료를 제외하거나 합성 자료로 교체했습니다.
- 공개용 문서 7개와 OCR 자료 2개는 개인정보 없는 합성 자료이며 문서 추출·인식 시험에 사용합니다.
- 이번 보안 반영 배포본은 수정한 현재 소스로 다시 빌드합니다. 과거 자료 정리 단계의 ‘실행파일 변경 없음’ 기록은 이번 실행파일에 적용하지 않습니다.

## 범위

이 정리는 배포 패키지에 포함된 개발·시험 자료를 대상으로 합니다. 사용자가 새로 입력한 문서의 개인정보를 자동 탐지하여 삭제하는 기능은 아닙니다. 검색에 필요한 공개 기관명, 매체 정보와 제3자 저작권 고지는 유지합니다.

프로그램은 작업 자동 저장 제어와 저장본·실행 로그 삭제 기능을 제공합니다. 자동 저장본은 평문이며, 수동 다운로드한 JSON·CSV·PDF와 원본 문서는 삭제 대상이 아닙니다. 구체적인 저장·외부 요청 범위는 [개인정보와 로컬 보관](../PRIVACY.md)에 설명합니다.

현재 보안 수정과 확인한 시험 결과는 [변경 기록](../CHANGELOG.md)과 [검증 기록](VALIDATION_KO.md)을 기준으로 합니다. 소스 패키지 작성이나 CI 설정 추가만으로 GitHub에 공개 게시되지는 않습니다.
