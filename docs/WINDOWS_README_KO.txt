RDAscraper 사용 안내

1. ZIP을 모두 압축 해제하고 RDAscraper.exe를 실행합니다.
2. 보도자료 문서를 선택하고 추출한 제목·핵심어·검색 기간을 확인합니다.
3. 기사 검색 후 날짜·매체·제목과 원문 링크를 확인하고 저장할 기사를 선택합니다.
4. 엑셀 XLSX, 한글 CSV, 검수 목록 PDF 중 필요한 형식으로 저장합니다.

함께 제공한 RDAscraper_Quick_Guide.pdf에서 4단계 사용법을 볼 수 있습니다.

실행 환경
Windows 10/11 64비트, Edge 또는 Chrome과 인터넷 연결이 필요합니다.
Python·Node.js·Go·별도 OCR 프로그램은 설치하지 않습니다.
문서 분석·한국어/영어 OCR·PDF 생성은 PC에서 처리합니다.
인터넷은 뉴스 검색과 기사 수집에 사용하며 검색어는 검색 서비스에 전달됩니다.

저장 파일
XLSX: 행 높이 30pt 등 표 서식을 유지합니다.
CSV: 표 데이터입니다. 행 높이나 글꼴 등 서식을 저장할 수 없습니다.
검수 목록 PDF: 선택 기사 정보·발췌문·원문 링크를 기존 기사 번호순으로 저장합니다.
기사 원문 전체와 사진은 기사 링크에서 확인합니다.

작업 보관
상단 작업 저장으로 JSON을 내려받고 작업 불러오기로 다시 엽니다.
자동 저장 설정은 상단 저장 설정에서 바꿀 수 있으며 기본값은 켜짐입니다.
자동 저장본은 브라우저 저장소와 %APPDATA%\RDAscraper에 평문으로 보관됩니다.
RDAscraper 로고를 누르면 현재 화면을 초기화합니다.
저장한 뒤 상단 종료 버튼으로 프로그램을 종료하세요.

업데이트
이전 프로그램이 실행 중이면 기존 화면에서 작업 저장 → 상단 종료를 진행한 뒤
교체 안내창에서 확인을 누릅니다. 창의 X만 닫으면 엔진이 남아 있을 수 있습니다.

배포 파일
이 배포의 식별 버전은 65.3.1입니다. 화면에는 버전 배지를 표시하지 않습니다.
SHA256SUMS.txt는 압축 안 파일의 일치 확인용이며 코드 서명을 대신하지 않습니다.
실행파일은 코드 서명되지 않았습니다. 제3자 라이선스는 licenses 폴더에 있습니다.
기관의 다운로드·실행 정책은 그대로 적용됩니다.
