# RDAscraper 시연 순서

현재 배포판의 사용 흐름은 **자료 입력 → 뉴스 검색 → 기사 검수 → 선택한 결과 저장**입니다. 아래 내용은 이 흐름을 설명하거나 녹화할 때 사용할 순서이며, 특정 PC에서 실제 검색과 저장을 검증했다는 기록은 아닙니다. 이 소스 패키지에는 시연 영상(MP4)이나 자막(SRT)이 포함되어 있지 않습니다.

## 1. 실행과 자료 입력

1. ZIP 압축을 해제하고 `RDAscraper.exe`를 실행합니다.
2. 공개된 보도자료의 HWP·HWPX·PDF·TXT·이미지 파일을 넣거나 제목과 본문을 직접 입력합니다.
3. 추출된 제목과 핵심어를 확인합니다. 이미지나 스캔 PDF를 OCR로 읽었다면 인식 결과를 검수하고 필요한 부분을 수정합니다.
4. 검색어에 미공개 연구내용이나 개인 연락처가 들어 있지 않은지 확인합니다.

## 2. 날짜 설정과 뉴스 검색

1. 보도자료 배포일과 검색 종료일을 맞춥니다.
2. 검색에 사용할 핵심어를 확인한 뒤 **뉴스 검색 시작**을 누릅니다.
3. 검색이 끝나면 기사 수와 검색 결과를 확인합니다. 실제 결과는 인터넷 연결과 검색 서비스의 응답에 따라 달라집니다.

시연 영상에는 검색 중 화면에서 결과가 나타나는 과정이 이어지도록 담습니다. 합성 응답을 사용한 기능 설명은 실제 뉴스 검색과 구분해 표시합니다.

## 3. 기사 검수와 선택

1. 기사 번호·기사일·매체·제목을 살펴봅니다.
2. 제목을 눌러 원문을 열고 제목·날짜·내용이 맞는지 확인합니다.
3. **확인 필요** 상태인 기사는 실제 원문을 확인한 뒤 포함 여부를 정합니다.
4. 기사 행을 눌러 저장할 기사를 선택하거나 해제합니다.

## 4. 결과 저장과 확인

| 저장 형식 | 확인할 내용 |
|---|---|
| 검수 목록 PDF | 선택한 기사가 기사 번호 오름차순으로 정리되는지 확인합니다. 기사 원문은 목록의 링크로 확인합니다. 번호가 건너뛰면 그 사이 기사가 선택되지 않았는지 살펴봅니다. |
| 엑셀 XLSX | 선택한 기사 목록을 정리·분석할 때 사용합니다. 기본 행 높이는 30pt로 고정됩니다. |
| 한글 CSV | 다른 도구에서 활용할 목록 데이터를 저장합니다. 줄바꿈은 정리되지만, CSV 자체에는 행 높이·서식이 저장되지 않습니다. |

저장한 파일을 직접 열어 선택한 기사와 일치하는지 확인합니다. 검수 목록 PDF는 목록과 원문 링크를 담으며, 기사 웹페이지 전체를 인쇄한 파일은 아닙니다.

## 5. 작업 보관과 마무리

나중에 이어서 작업하려면 상단 **작업 저장**으로 보관하고, **작업 불러오기**로 다시 엽니다. 처음부터 시작하려면 필요한 작업을 저장한 뒤 왼쪽 상단 **RDAscraper** 로고를 누릅니다.

영상의 끝에는 “연구성과 홍보를 돕는 RDAscraper” 문구를 약 3초간 보여 줄 수 있습니다. 설명 화면에는 현재 제공하는 버튼과 저장 형식만 사용합니다.

## 공개 시연 자료에 포함할 내용

공개된 보도자료나 합성 시험 문서를 사용하고, 담당자 연락처·개인 파일 경로·미공개 문서·작업 저장본이 화면에 노출되지 않도록 확인합니다. 실제 실행 영상을 공개할 때에는 사용한 운영체제와 실제 검색 또는 합성 응답 구간을 정확히 표시합니다.
