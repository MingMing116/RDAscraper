# 검수 목록 PDF 사용 안내

검수 목록 PDF는 **선택한 기사의 정보와 발췌문을 번호순으로 정리하는 파일**입니다. 결과를 공유하거나 출력해 검토할 때 사용합니다.

## 저장 순서

1. **기사 검수**에서 날짜·매체·제목을 확인합니다.
2. 기사 제목을 눌러 원문을 확인하고, 저장할 기사 행을 선택합니다.
3. **결과 저장**에서 **검수 목록 PDF**를 누릅니다.
4. 내려받은 `RDA_검수목록_날짜.pdf`를 열어 선택 기사와 번호를 확인합니다.

PDF에는 기사 번호·기사일·매체·제목·발췌문·원문 링크 등 기사 정보가 들어갑니다. 원문 전체와 사진은 링크를 눌러 확인하세요. PDF 생성은 PC에서 처리하며 별도 인쇄 브라우저를 실행하지 않습니다.

## 번호는 어떻게 정렬되나요?

화면에서 정렬을 바꾸더라도 PDF는 기존 기사 번호의 오름차순으로 저장합니다. 선택하지 않은 번호는 그대로 비워 둡니다.

예를 들어 1~24번 중 8·14번을 제외했다면 총 22건이 **1~7, 9~13, 15~24번** 순서로 나옵니다. 선택에서 제외한 번호를 채우기 위해 다른 기사의 번호를 바꾸지 않습니다.

## 어떤 파일을 선택하면 되나요?

| 목적 | 저장 버튼 |
| --- | --- |
| 기사 정보를 정돈된 문서로 공유·출력 | 검수 목록 PDF |
| 일정한 행 높이로 확인·필터·편집 | 엑셀 XLSX |
| 다른 프로그램에 기사 데이터를 전달 | 한글 CSV |

XLSX는 모든 행 높이를 30pt로 고정합니다. CSV에는 행 높이·글꼴·열 너비를 저장할 수 없으므로 셀 안 줄바꿈·탭·연속 공백을 정리합니다.

## 검수와 보관

발췌문은 기사 전체가 아닙니다. 제목·날짜·본문의 일치 여부는 **판별 근거 보기**와 원문 링크에서 확인하세요. 직접 보완한 본문 전체는 작업 JSON에 보관되며 검수 목록 PDF에 전체 출력되지 않습니다.

PDF의 글자는 내장 글꼴로 일정하게 표시합니다. 화면의 글자 크기 설정은 PDF 크기에 영향을 주지 않습니다. 저장된 파일은 사용자가 선택한 위치에 남고, 작업 자동 저장본을 삭제해도 함께 삭제되지 않습니다. [개인정보와 로컬 보관](../PRIVACY.md)

이번 배포의 실제 검사 범위와 Windows 확인 여부는 [검증 기록](VALIDATION_KO.md)에 구분합니다.
