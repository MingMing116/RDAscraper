PDF 작성기 시험에는 저수준 텍스트 본문 작성 회귀검사가 남아 있습니다. 화면에서 기사 본문 PDF를 제공한다는 뜻은 아닙니다. 현재 저장 메뉴는 XLSX·CSV·검수 목록 PDF입니다.

## 이번 환경에서 완료하지 못한 검사

실제 Chromium 통합 검사와 실제 뉴스 검사 실행을 시도했으나, 브라우저가 시작될 때 제작환경에서 `socket(): Operation not permitted` 오류가 발생했습니다. 앱 시나리오와 실제 뉴스 검색 이전에 중단되어 통과로 기록하지 않습니다. Windows 실기기·설치된 Edge 실행, 이번 EXE의 실제 뉴스 검색부터 PDF 저장까지의 전 과정은 확인하지 못했습니다. Linux에서 실행한 시험을 Windows 검증으로 표시하지 않습니다.

Windows 빌드·패키징 및 GitHub Actions 설정은 포함했지만 원격 Actions와 Windows PowerShell 패키징 스크립트는 이번 환경에서 실행하지 않았습니다. 제공 ZIP은 해당 구성으로 별도 생성하고 내용·해시를 검사했습니다. [공개 절차](PUBLISH_KO.md)의 Windows 검사 방법을 사용하세요.

## 공개 자료와 검사 범위

공개 소스에는 재현 가능한 합성 시험 문서와 시험 코드를 포함합니다. 사용자 제공 문서의 해시·크기·추출 결과 등 입력 자료에 관한 기록과 과거 내부 검증·영상 제작 기록은 공개 자료에서 제외합니다. 소스 파일 목록의 해시는 공개 소스 자체에만 적용합니다.

이 기록은 로컬 소스와 배포 파일 검사 결과입니다. 과거 Git 커밋·브랜치·태그·삭제된 파일·Release 첨부 파일 전체에 대한 감사 결과를 뜻하지 않습니다. 정적 검사는 알려진 형태와 확인 가능한 문맥을 점검한 결과이며 기관의 공개 승인이나 모든 형태의 정보 부재를 보증하는 자료가 아닙니다.
